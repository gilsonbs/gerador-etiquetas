# Gerador de Etiquetas 

Ferramenta web para criar e imprimir etiquetas de preço e cartão de funcionários para as **Drogarias Max**.

Acesse online: **https://gilsonbs.github.io/gerador-etiquetas/**

---

## Modelos disponíveis

| Modelo | Etiquetas por folha | Uso |
|--------|--------------------:|-----|
| 1 | 4 (2×2) | Etiqueta de produto grande |
| 2 | 1 (folha inteira) | Destaque / promoção |
| 3 | 9 (3×3) | Etiqueta de produto média |
| 4 | 24 (3×8) | Etiqueta de produto pequena |
| 5 | 10 (2×5) | Cartão de funcionário |

## Funcionalidades

- Geração de PDF pronto para impressão (folha A4)
- Logo Drogarias Max já embutida — sem necessidade de upload
- Preço formatado com R$ automático (menor, na mesma linha)
- Campo de emoji/ícone abaixo do preço (🔥 ⭐ 💊 e outros)
- Cores de fundo e texto personalizáveis por etiqueta
- Tema claro/escuro
- Rascunho salvo automaticamente no navegador

## Como usar

1. Abra o link acima (ou o arquivo `index.html` diretamente no navegador)
2. Escolha o modelo de etiqueta
3. Preencha os campos e ajuste as cores
4. Clique em **Avançar → Imprimir / PDF**

Nenhuma instalação necessária. Funciona 100% no navegador.
